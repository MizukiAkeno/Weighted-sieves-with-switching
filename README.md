# Weighted-sieves-with-switching


This repository provides a Python implementation of the weighted-sieve computations arising from Kaisa Matomäki and Sebastian Zuniga-Alterman's paper [*Weighted sieves with switching*](https://arxiv.org/abs/2405.19063). It was developed for the numerical calculations in [*On the level of distribution of Goldbach primes and its applications*](https://arxiv.org/pdf/2606.29559). Nearly all of the code and accompanying documentation were generated by AI, but their mathematical content and numerical output were subsequently checked by the author. Compared with the code included with version 1 of that paper, this implementation is shorter and faster, while producing higher-precision certified results.






For given parameters $`k`$, $`\theta`$, and $`s`$, define

```math
G(u_1,\ldots,u_r)
=
\max\left(0,1-\sum_{i=1}^r F(u_i)\right).
```

The quantity $`S_G`$ is defined by

```math
S_G=\sum_{r=k+1}^{\infty}T_r,
```

where

```math
T_r=
\int_{\substack{
1/s\leq u_1\leq\cdots\leq u_r\leq1\\
u_1+\cdots+u_r=1
}}
\frac{G(u_1,\ldots,u_r)}
     {u_1\cdots u_r}\,du.
```

The variables are restricted to the ordered region

```math
u_1\leq\cdots\leq u_r.
```

Since the integrand is symmetric in the variables, integration over this
ordered region is equivalent to multiplying the integral over the full
region by $`1/r!`$. Thus, the factorial appearing in the original definition
of $`M_k`$ is already incorporated into $`S_G`$.

The value of $`M`$ is calculated from

```math
M
=
s\omega^-(s\theta)
-
s\int_{1/s}^{\theta}
\frac{F(u)\omega^+(s(\theta-u))}{u}\,du
-
\frac{2}{\theta}S_G.
```

In the code, these three terms are denoted by

```math
M_0=s\omega^-(s\theta),
```

```math
M_1
=
s\int_{1/s}^{\theta}
\frac{F(u)\omega^+(s(\theta-u))}{u}\,du,
```

and

```math
M_2=\frac{2S_G}{\theta}.
```

Therefore,

```math
M=M_0-M_1-M_2.
```

A positive lower endpoint of the computed interval for $`M`$ certifies that
$`M>0`$.

### Linear sieve functions

Put

```math
A^\pm(x)=x\omega^\pm(x).
```

The initial values are

```math
A^+(x)=2 \qquad (0\lt x\leq3),
```

and

```math
A^-(x)=0 \qquad (0\lt x\leq2).
```

For larger $`x`$, they are computed recursively from the delay differential
equations

```math
(A^+)'(x)=\frac{A^-(x-1)}{x-1},
```

and

```math
(A^-)'(x)=\frac{A^+(x-1)}{x-1}.
```

If

```math
\beta=s\theta,
```

then the first term of $`M`$ is evaluated as

```math
M_0
=
s\omega^-(\beta)
=
s\frac{A^-(\beta)}{\beta}.
```

### The functions $`c_r`$

Define

```math
c_1(x)=\mathbf{1}_{x\geq1},
```

and, for $`r\geq2`$,

```math
c_r(x)
=
\int_r^x\frac{c_{r-1}(v-1)}{v-1}\,dv.
```

These functions satisfy

```math
c_r(s)
=
\int_{\substack{
1/s\leq u_1\leq\cdots\leq u_r\\
u_1+\cdots+u_r=1
}}
\frac{du}{u_1\cdots u_r}.
```

They are used to reduce the multidimensional integrals defining $`S_G`$ to
one-dimensional recursive integrals.

The relevant delay-differential functions are evaluated using the midpoint power-series method of [Marsaglia, Zaman, and Marsaglia](https://doi.org/10.1090/S0025-5718-1989-0969490-3).

## Trivial weight

For the trivial weight

```math
F(u)=0,
```

we have

```math
G(u_1,\ldots,u_r)=1.
```

Consequently,

```math
T_r=c_r(s).
```

Since $`u_i\geq1/s`$ and $`\sum_i u_i=1`$, the integration region is empty
when $`r>s`$. Hence

```math
S_G
=
\sum_{r=k+1}^{\lfloor s\rfloor}c_r(s).
```

Moreover, the integral containing $`F`$ vanishes, so

```math
M_1=0.
```

Thus,

```math
M
=
s\frac{A^-(s\theta)}{s\theta}
-
\frac{2}{\theta}
\sum_{r=k+1}^{\lfloor s\rfloor}c_r(s).
```

## Kuhn weight

For Kuhn's weight,

```math
F(u)=\frac12\mathbf{1}_{u\leq1/t}.
```

In this case,

```math
T_r=T_{r,0}+T_{r,1},
```

where

```math
T_{r,0}=c_r(t)
```

and

```math
T_{r,1}
=
\frac{t}{2}
\int_{t-1}^{\,t(1-1/s)}
\frac{c_{r-1}(v)}{v(t-v)}\,dv.
```

Therefore,

```math
S_G
=
\sum_{r=k+1}^{\lfloor t\rfloor+1}
\left(
c_r(t)
+
\frac{t}{2}
\int_{t-1}^{\,t(1-1/s)}
\frac{c_{r-1}(v)}{v(t-v)}\,dv
\right).
```

Here $`c_r(t)=0`$ when $`r>t`$.

For the middle term in $`M`$, put

```math
\alpha=t\theta,
\qquad
\beta=s\theta.
```

Then

```math
\int_{1/s}^{\theta}
\frac{F(u)\omega^+(s(\theta-u))}{u}\,du
=
\frac12\int_{1/s}^{1/t}
\frac{\omega^+(s(\theta-u))}{u}\,du.
```

After the substitution

```math
v=s(\theta-u),
```

this becomes

```math
\frac12
\int_{\beta(1-1/\alpha)}^{\beta-1}
\frac{A^+(v)}{v(\beta-v)}\,dv.
```

Hence

```math
M_1
=
\frac{s}{2}
\int_{\beta(1-1/\alpha)}^{\beta-1}
\frac{A^+(v)}{v(\beta-v)}\,dv.
```

Finally,

```math
M
=
s\frac{A^-(\beta)}{\beta}
-
\frac{s}{2}
\int_{\beta(1-1/\alpha)}^{\beta-1}
\frac{A^+(v)}{v(\beta-v)}\,dv
-
\frac{2S_G}{\theta}.
```

## Certified numerical evaluation

The functions $`A^\pm`$ and $`c_r`$ are represented on each unit interval by
Taylor polynomials with rigorous remainder bounds.

For the final calculation, the Taylor degree is $`60`$ and the Arb working
precision is $`256`$ bits. Integrals crossing integer points are divided at
those points so that each part uses a single Taylor model.

Integrals of the form

```math
\int_a^b\frac{f(v)}{v(B-v)}\,dv
```

are evaluated using

```math
\frac{1}{v(B-v)}
=
\frac{1}{B}
\left(
\frac1v+\frac1{B-v}
\right).
```

All coefficients, remainder bounds, function values, integrals, and final
arithmetic operations are evaluated using Arb interval arithmetic.
Consequently, the final interval is guaranteed to contain the exact value
of $`M`$.
